# AI Usage Info

## Sinn der Library

Eine OpenAI Library ohne externe Abhängigkeiten. Die Verbindung wird mit CURL aufgebaut und nutzt ausschließlich die OpenAI Responses API (`POST /v1/responses`).

## Öffentliche Klassen

- `Phore\AiHarness\Client\OpenAiClient`: CURL-Client für nicht-streaming und streaming Responses-API-Aufrufe.
- `Phore\AiHarness\Client\AiRequest`: Request-Value-Object für Responses-API-Payloads.
- `Phore\AiHarness\Client\AiResponse`: Response-Value-Object mit Zugriff auf Status, Header, Body und Output-Text.
- `Phore\AiHarness\Client\AiRequestSpooler`: verarbeitet mehrere `AiRequest`-Instanzen parallel über `curl_multi`.
- `Phore\AiHarness\Client\AiRequestException`: wird bei CURL-/Kommunikationsfehlern oder HTTP-Fehlerstatus der OpenAI API geworfen und enthält optional die `AiResponse`.

## Kurzbeispiel

```php
use Phore\AiHarness\Client\AiRequest;
use Phore\AiHarness\Client\OpenAiClient;

$client = OpenAiClient::fromEnvironment();
$response = $client->createResponse(AiRequest::text('gpt-4.1-mini', 'Sag Hallo'));
echo $response->getOutputText();
```

Streaming:

```php
$finalResponse = $client->streamResponse(
    AiRequest::text('gpt-4.1-mini', 'Zähle bis drei'),
    function (array $event): void {
        if (($event['type'] ?? null) === 'response.output_text.delta') {
            echo $event['delta'];
        }
    },
);
```
